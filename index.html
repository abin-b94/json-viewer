            What is JSON?
          

          

            JSON (JavaScript Object Notation) is a lightweight, text-based data interchange format based on a subset of JavaScript syntax. It is language-independent, human-readable, and universally supported across modern programming languages, APIs, and databases.
          

          

            JSON structures consist of collections of name/value pairs (objects) and ordered lists of values (arrays). Standard value types include strings, numbers, booleans, objects, arrays, and null.
